# 書狀與證物品管

目錄：1 格式規定｜2 內容檢查清單｜3 事實措辭的六條規則｜4 圖片、截圖、掃描的精讀程序｜5 PDF 定稿檢查｜6 列印、簽名、繳費、寄送｜7 寄出後追蹤

## 1. 格式規定

依民事訴訟書狀規則（民國114年8月29日修正，2026-10-28 核對全文）。

### 第3條：書狀本身

- **紙張與書寫：**A4，中文直式橫書，由左至右。
- **以電腦文書處理製作為原則。**例外包括：
  - 未委任訴訟代理人的自然人，釋明因年齡、學歷、身心狀況、經濟弱勢等原因不能以電腦製作
  - 小額程序使用表格化訴狀
  - 經法院同意
- **電腦製作的格式：**
  - 上下左右邊界各 2.5 公分
  - 字型 14 號以上、20 號以下
  - 行距為單行間距，或固定行高 25 點以上、30 點以下
  - 頁面底端編頁碼
  - 總頁數逾 30 頁，首頁編目錄
  - 雙面列印
- **手寫：**黑色或藍色墨水，底端編頁碼。

### 第4條：證據與文件

- 證據與文件宜在第一頁頂端靠右或置中標示編號，並在底端編頁碼。
- 非 A4 的證據宜黏貼於 A4 白紙，或折疊成 A4。

### 第5條：不合格式的後果

- 未依格式製作，經法院定期通知補正而未補正者，法院得拒絕書狀的提出。
- 補正前，法院得不將書狀分與法官辦理。

### 民訴的相關規定

- 記載事項：民訴116
- 簽名或蓋章：民訴117
- 繕本或影本的份數按他造人數：民訴119

刑事、家事、行政訴訟另有書狀規定或範例，見 references/04 第 7 節。

## 2. 內容檢查清單

**基本資料**
- [ ] 法院全名、書狀名稱、案號與股別（新案沒有案號時，寫相關的執行案號）
- [ ] 當事人姓名、住址；電話欄留給本人手寫

**聲明與理由**
- [ ] 聲明具體、可執行，並與理由一致
- [ ] 每一句事實都對應到證物編號；沒有證據的寫「原告陳述」或請求調查
- [ ] 金額逐筆加總正確；日期統一用民國，不和西元混用；同一筆金額全文寫法一致
- [ ] 證物目錄、證物頁首標籤、內文引用三方一致（編號、日期範圍、頁數）
- [ ] 每一頁證物都有標籤；附件頁碼沒有壓到證物原有的頁首、頁尾（網頁列印常有網址頁尾，要目視）

**引用與資料保護**
- [ ] 引用的條文與字號都在查證紀錄中標「已核實」
- [ ] 帳號、身分證字號只出現在必要處；對話和說明文件中只寫末幾碼
- [ ] 沒有寫到與本案無關的人、車、事件

**最後一頁與附件**
- [ ] 簽名或蓋章欄、具狀日期欄留空，由本人親寫
- [ ] 繕本份數、費用、附件清單

## 3. 事實措辭的六條規則

實例見 references/06 第 5 節。

1. **提議不等於已發生。**「要不要我去收」是提議，不能寫成「被告曾到場收款」。
2. **推算不等於記憶。**從缺證月份推算出的月份，不能寫成「原告記憶為……」；要寫「該月份付款資料待補」。
3. **沒有日期標記，不推定日期。**截圖第一段沒有日期分隔線，就只寫到能證明的精度，例如只寫到月份，不寫推算出的「某日前一日」。
4. **沒顯示金額的確認訊息，不是金額證據。**「收到了」可以證明有付款紀錄，但金額要請法院調銀行資料核對。
5. **模糊的單據要說它模糊。**看得清楚的才寫「可辨識」，模糊的那筆另外說明並請求核對。
6. **舊的自我陳述只是脈絡。**當事人過去訊息裡的自我試算，只是當時的說法，不能獨立證明對方做了什麼。

## 4. 圖片、截圖、掃描的精讀程序

這一節是避免打錯字的核心。法院看到一個錯的日期或金額，可能懷疑整份書狀的可信度。

### 步驟

1. **用最原始的檔案。**順序是：原始照片或原檔 > 截圖 > 掃描 > 翻拍或傳真。手上只有壓縮過的圖，就向使用者要原檔。
2. **先看整體，再分區放大。**
   - `python -E -P scripts/img_zoom.py 圖檔 --grid 2x3 --out 資料夾`：分格放大，格子之間預設重疊 8%，避免一行字被切斷。
   - 單一欄位用 `--box 左,上,右,下`（0～1 比例）。字很淡時加 `--enhance`。
   - PDF 用 `--page N`。
3. **關鍵欄位讀兩次。**
   - 關鍵欄位：日期、時間、金額、案號、帳號末碼、姓名、車號。
   - 第二次換一個放大倍率，或換用 `--enhance`。兩次一致才採用。
   - PDF 有文字層時，再和抽出的文字比對一次。
4. **數字逐位核對。**容易混淆的字：

   | 類別 | 例子 |
   |---|---|
   | 數字 | 0／6／8／9、3／5／8、1／7、2／7 |
   | 形近字 | 己／已／巳、未／末、日／曰、千／干、戊／戌／戍、王／玉、土／士、人／入 |
   | 符號與格式 | 全形與半形、～（U+FF5E）與 ~、逗號千分位 |
   | 年份與時段 | 民國與西元（115 年 ＝ 2026 年）、上午與下午 |

5. **看不清就標〔?〕。**例如「1〔?〕,000元」，並把它列入「請使用者確認」清單。不要用前後文、常理或「金額應該一樣」補上。
6. **交叉核對。**拿收據金額比對銀行明細、對話時間、轉帳通知；對不上的，列為待確認。
7. **轉錄完再回頭逐行比一次原圖。**
8. **LINE 截圖要注意：**
   - 日期以畫面中的日期分隔線為準；沒有分隔線的訊息，日期只能寫到可證明的範圍。
   - 左右兩側分別是誰，以截圖上的頭像與名稱確認。LINE 通常是左邊為對方、右邊為本人，但每份截圖都要確認。
   - 「已讀」與時間戳記照原樣記錄，不推論對方的意思。
   - 不刪、不改、不重排截圖；要遮蔽個資，另存遮蔽版，並保留原檔。

### 轉錄輸出格式

下表是格式範例，不是任何案件的真實資料。

| 證物 | 欄位 | 轉錄內容 | 讀取方式 | 可信度 |
|---|---|---|---|---|
| 證○-○ | 存款日期 | ○○○/○○/○○ | 放大 3 倍讀兩次一致 | 高 |
| 證○-○ | 金額 | 1〔?〕,000 | 原圖模糊 | 待使用者確認 |

## 5. PDF 定稿檢查

```bash
python -E -P scripts/pdf_check.py A.pdf --words 字詞清單.txt --compare 上一版.pdf --render 檢查圖 --pages 1,6 --exhibits 7-23
```

- **證物頁範圍：**書狀後面接證物時，用 `--exhibits` 指定證物頁。沒指定時，腳本用「有沒有影像」猜，純向量的網頁列印證物會被誤報邊界與字級。
- **沒內嵌的字型：**頁碼或標籤用 PDF 內建的中文字型（Fangti）時，字型不在檔案裡，要靠閱讀或列印程式補字。印前請使用者看預覽，確認頁碼與小字都有顯示。

- **字詞清單：**
  - 每改一處，就把新寫法加為必含詞，把被刪掉的錯誤寫法加為禁止詞（行首加 `!`）。
  - 例：刪掉「原告記憶」的寫法後，加 `!原告記憶` 為禁止詞，並把改寫後的新句子加為必含詞。
  - 腳本比對前會去掉空白與換行。仍找不到時，可能是頁首或表格的抽取順序打亂了文字，要看輸出的 PNG 確認。
- **逐頁比對：**用 `--compare` 確認這一版和上一版只有預期的頁面不同。
- **目視：**輸出關鍵頁的 PNG，檢查簽名欄、日期欄、頁碼、證物標籤。
- **鎖定版本：**
  - 記下定稿的 SHA-256（腳本會印出來），放在唯一一個「要印這個」資料夾。
  - 舊版和其他 AI 的版本不要放在一起，以免印錯。
- **最後看結論：**腳本會列出要處理的項目。格式以書狀頁為準；證物頁的邊界、字級只供參考。

## 6. 列印、簽名、繳費、寄送

- **列印：**A4、實際大小 100%，不要「符合頁面」，也不要一張印多頁；雙面列印。照片類證物建議彩色。
- **份數：**每份文件印法院正本 1 份，加上依對造人數的繕本，自己另留 1 份。
- **本人親寫：**電話、具狀日期、簽名或蓋章。簽名前，本人要再讀一次事實段落，確認都是親身經歷。
- **費用：**照法院的繳費方式。郵寄時可附郵政匯票，受款人寫法院全名，每筆費用分開，並標明用途。
- **寄送：**掛號附回執，寄到法院收發室。信封註明書狀種類與急件；有相關案號就寫上。收據保留好。

## 7. 寄出後追蹤

1. 查收件與分案，取得新案號與股別。
2. 注意補費、補正裁定。實務常見限 5 日（也見過 3 日），逾期駁回，例如新北地院114年度聲字第354號。
3. 開庭通知：確認日期、地點或遠距方式（民訴211-1），並準備爭點表。
4. 准許停止執行時：
   - 在期限內提存擔保（提存法5）。
   - 把提存書影本陳報執行處。
   - 確認執行處已通知第三人。
5. 新證據到手後，用補充書狀（或準備書狀）提出，並註明證物編號接續原編號。
