# 合約審查（以 taiwan-claude-legal 為核心）

**來源：**審查流程、掃描清單的主幹、引用格式、免責聲明與常見錯誤，改寫自 tern/taiwan-claude-legal（Apache-2.0，commit 1edf508，2026-08-26）的 `skills/taiwan-legal-audit/SKILL.md`。

**本檔改了什麼：**
- 譯成繁體中文。
- 清單上的條文逐條用 law_fetch.py 核對（2026-10-29），並補上勞動契約常見的競業禁止、最低服務年限。
- 加上本 skill 的查證規則，以及個人常見合約的分級（原 references/08 第 5 節）。
- 原作沒有標示作者的法律專業資格；採用前已逐條核對官方原文。

目錄：1 適用範圍｜2 審查流程｜3 多法規風險掃描清單｜4 輸出格式與分級｜5 常見錯誤｜6 範例：離職預告與扣薪

## 1. 適用範圍

- **商務與勞動：**保密協議（NDA）、勞動契約、服務、委任或承攬合約、股東協議、隱私權政策、著作授權。
- **個人常見：**借據、本票、保證、租約、買賣、平台服務條款。
- **不適用：**已經進入訴訟或強制執行的契約爭議，先看 references/03；要寫成書狀的部分，照 references/05。

## 2. 審查流程（五步）

1. **載入條文。**依合約類型，先在本地快照找相關條號，再用 law_fetch.py 抓官方原文。

   | 合約類型 | 先查的法規（`laws/` 目錄） |
   |---|---|
   | 一般合約 | 民法（civil-code） |
   | 勞動、僱傭 | 勞動基準法（labor-standards-act），再看民法 |
   | 公司、股權 | 公司法（company-act），再看民法 |
   | 隱私、個資 | 個人資料保護法（pdpa） |
   | 智財、授權 | 著作權法（copyright-act） |
   | 消費者定型化契約 | 消費者保護法（consumer-protection），再看民法 |
   | 本票、保證、借款 | 票據法（negotiable-instruments），再看民法 |

   - 找條號：`python -I scripts/law_search.py 競業禁止 --law labor-standards-act`
   - 快照只用來找條號；引用的文字、項與款，以 law_fetch.py 抓到的官方原文為準。
2. **判斷合約類型與當事人。**
   - 有沒有勞工或消費者這類受特別保護的一方。
   - 是不是一方預先擬好、用於同類契約的定型化條款。
   - 準據法與管轄怎麼約定。
3. **多法規風險掃描。**逐條對照第 3 節清單。
4. **輸出與引用。**依第 4 節的格式與分級。
5. **結尾。**依 SKILL.md「回覆格式」附審閱提示，最後一行附免責聲明。

## 3. 多法規風險掃描清單

每列都在 2026-10-29 用 law_fetch.py 核對官方原文；用前重抓。

| 檢查點 | 規定重點 | 依據 |
|---|---|---|
| 違反強制或禁止規定 | 法律行為違反強制或禁止之規定者無效；但規定並不以之為無效者，不在此限 | 民法71 |
| 背於公序良俗 | 無效 | 民法72 |
| 違約金過高 | 約定之違約金額過高者，法院得減至相當之數額 | 民法252 |
| 定型化條款（一般） | 一方預定用於同類契約的條款，有免除或減輕預定方責任、加重他方責任、使他方拋棄或限制權利等情形，按其情形顯失公平者，該部分約定無效 | 民法247-1 |
| 定型化條款（消費者） | 違反誠信原則、對消費者顯失公平者，無效 | 消保法12 |
| 特別法優先 | 法規對同一事項有特別規定者，應優先適用；勞基法未規定者，才適用其他法律 | 中央法規標準法16；勞基法1Ⅰ |
| 勞動條件最低標準 | 雇主與勞工所訂勞動條件，不得低於勞基法所定之最低標準 | 勞基法1Ⅱ |
| 離職後競業禁止 | 要同時符合四款：雇主有應受保護之正當營業利益、勞工能接觸或使用營業秘密、期間區域範圍未逾合理範疇、有合理補償（不含在職期間的給付）。違反任一款無效；最長 2 年，逾 2 年縮短為 2 年 | 勞基法9-1 |
| 最低服務年限 | 雇主須提供專業技術培訓並負擔費用，或提供合理補償；不得逾合理範圍；違反者無效。因不可歸責於勞工的事由提前終止，勞工不負違約或返還訓練費用之責 | 勞基法15-1 |
| 扣薪抵違約金 | 雇主不得預扣勞工工資作為違約金或賠償費用 | 勞基法26 |
| 預告期間 | 雇主終止依年資 10、20、30 日前預告；勞工終止不定期契約，準用同一期間預告雇主 | 勞基法16Ⅰ、15Ⅱ |
| 股份轉讓限制 | 除公司法另有規定外，不得以章程禁止或限制；設立登記前不得轉讓 | 公司法163 |
| 個資蒐集依據 | 非公務機關蒐集或處理個資，要有特定目的，並符合法定情形之一，例如有契約關係且已採取適當安全措施、經當事人同意 | 個資法19Ⅰ |
| 告知義務 | 向當事人蒐集時，應明確告知機關名稱、蒐集目的、資料類別、利用的期間地區對象方式、當事人權利與行使方式、不提供的影響 | 個資法8Ⅰ |
| 目的外利用與行銷 | 原則在特定目的必要範圍內利用；當事人拒絕行銷時應即停止；首次行銷應提供拒絕方式並負擔費用 | 個資法20 |
| 職務上完成之著作 | 以受雇人為著作人，但可約定以雇用人為著作人；著作財產權歸雇用人，但可另約定 | 著作權法11 |
| 出資聘人完成之著作 | 以受聘人為著作人，但可另約定；財產權依約定，未約定者歸受聘人，出資人得利用 | 著作權法12 |
| 著作人格權 | 專屬著作人本身，不得讓與或繼承。合約寫「讓與著作人格權」要特別標出【推論，依條文文字】 | 著作權法21 |
| 合意管轄 | 可合意定第一審管轄法院，但限於由一定法律關係而生之訴訟，並應以文書證之 | 民訴24 |
| 本票、保證 | 本票執票人可聲請法院裁定後強制執行；保證人要代負履行責任 | 票據法123；民法739 |
| 借款實交額 | 消費借貸是移轉金錢所有權；預扣利息不算本金，見 references/03 第 9 節 | 民法474 |

清單沒列到的條款，先用 law_search.py 找條號，再照同樣方法核對。

## 4. 輸出格式與分級

- **語言：**繁體中文、台灣用語，寫「合約」或「契約」，不寫「合同」。
- **引用：**每個條文都附全國法規資料庫的連結，格式如下；條號有「之」時寫成 `flno=9-1`。

  `依據 [民法第 71 條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=71)`
- **資料來源：**寫明「全國法規資料庫」，查詢日寫在審閱提示。
- **逐條寫法：**條款原文（引號內逐字）→ 問題 → 依據（連結）→ 建議改法。
- **分級**（原 references/08 第 5 節）：

  | 分級 | 意思 | 例子 |
  |---|---|---|
  | 🟢 可以簽 | 條款清楚、雙方對等 | 當事人、標的、價金、期限、解約方式都寫明，沒有異常的違約金 |
  | 🟡 要問清楚 | 有一兩條要修改或確認 | 違約金偏高（民法252）、管轄法院約定在遠方（民訴24）、自動續約、競業禁止沒有補償（勞基法9-1） |
  | 🔴 先停 | 可能造成重大且難以挽回的責任 | 要求簽空白本票或附本票（票據法123）、擔任保證人（民法739）、借款金額與實際交付金額不符（民法474）、約定預扣工資抵違約金（勞基法26） |

- **每份合約都要看：**
  - 當事人身分
  - 標的、金額與付款方式
  - 期限與終止
  - 違約責任
  - 管轄法院
  - 簽名或蓋章、日期與份數
  - 附件是否齊全

## 5. 常見錯誤

原作列的：
- 沒先讀相關條文就分析。
- 特別法和普通法弄混，例如勞動事項只套民法、忽略勞基法。
- 用非台灣用語，例如「合同」。
- 引用沒附官方連結。

本 skill 補充：
- 用快照直接引用條文：快照只用來找條號，引用前要用 law_fetch.py 核對原文與項次。
- 把條文沒寫的效力寫成定論，例如「通常無效」。要查實務（references/07 第 7 節）；查不到就標【待判斷】。

## 6. 範例：離職預告與扣薪

改寫自原作範例。原作把「約定長於法定的預告期間」寫成「通常無效」；條文沒有直接規定，這裡改標【待判斷】。

**使用者：**「公司說如果不提早三個月預告離職，就要扣我最後一個月的薪水，這合法嗎？」

**回覆要點：**
1. 🛑 **扣薪不行。**雇主不得預扣勞工工資作為違約金或賠償費用，依據 [勞動基準法第 26 條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=N0030001&flno=26)。
2. **法定預告期間：**勞工終止不定期契約，準用第 16 條第 1 項的期間預告雇主：
   - 年資 3 個月以上未滿 1 年：10 日
   - 1 年以上未滿 3 年：20 日
   - 3 年以上：30 日

   依據 [勞動基準法第 15 條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=N0030001&flno=15)、[第 16 條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=N0030001&flno=16)。
3. ⚠️ **約定三個月預告是否有效：**條文沒有直接規定，屬解釋問題【待判斷】。分析起點是勞動條件不得低於勞基法最低標準【推論】，依據 [勞動基準法第 1 條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=N0030001&flno=1)。下結論前要先查實務見解。
