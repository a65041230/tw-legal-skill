# 查證來源與方法

目錄：1 什麼才算「已核實」｜2 官方系統｜3 條文｜4 裁判｜5 判例、決議與大法庭｜6 函釋｜7 費用、地址、電話｜8 查證紀錄格式

## 1. 什麼才算「已核實」

| 對象 | 已核實的條件 |
|---|---|
| 條文 | 這次用 `law_fetch.py` 或在全國法規資料庫開啟該條，看到法規名稱、條號、修正日期與全文 |
| 裁判 | 這次在司法院裁判書系統打開全文，核對法院、年度、字別、號次、裁判日期、案由，並找到要引用的那一段原文 |
| 裁判中引用的另一則裁判 | 只能寫成「某裁定引用最高法院某號意旨」。要直接引用那一則，必須另外打開它的原文 |
| 費用、網址、電話 | 這次在官方網站看到 |

**不算核實：**
- 第三方法律資料庫的內容，包括 TLR 法律 MCP（references/07）。可以用來找候選，引用前仍要到官方系統打開原文
- 搜尋引擎摘要、新聞、部落格、事務所文章
- 對方書狀、記憶
- AI 的回答，包括你自己這次或之前說過的話

這些只能當線索：拿到字號後，去官方系統打開原文。

## 3. 條文

### 抓條文

```bash
python -I scripts/law_fetch.py B0010001:77-13 B0010004:18
python -I scripts/law_fetch.py --find 消費者債務清理條例
python -I scripts/law_fetch.py --law B0010054
```

**注意事項：**
- 輸出的修正日期是整部法規的最後修正日，不一定是你要的那一條。沒修正過的命令（例如準則、辦法）只有「發布日期」，腳本會照印。
- 要知道哪幾條改過、何時施行，看沿革：`https://law.moj.gov.tw/LawClass/LawHistory.aspx?pcode=代碼`。
- 公布日不等於施行日。例如民法第205條（利率上限 16%）是 110/1/20 公布、公布後六個月施行；民法第1223條 115/8/17 公布、公布六個月後施行。
- 事情發生在修法前後時，要確認行為時適用哪一版，以及有沒有施行法或過渡規定。
- 全國法規資料庫每週五更新，當週發布的法規下週五才上線（網站頁尾說明）。剛修法的條文要另查主管機關公告。
- 條文裡的表格（例如在途期間標準的附表）會用框線字元印出來，很長，可以導到檔案再查。若出現「※ 本條提到表格、附表或附件，但沒抓到表格內容」，就開網址看原表，不要憑文字推算天數或金額。
- 網路偶爾斷線時，腳本會重試；仍失敗會印「!! 查詢失敗」。失敗就是沒查到，不能當成已核實。

### 本地快照（找條號用）

- `laws/` 有 12 部常用法規的全文快照，清單與日期見 `laws/README.md`。
- **用途：**不知道是哪一條時，用關鍵字找，例如 `python -I scripts/law_search.py 競業禁止 --law labor-standards-act`。多個關鍵字表示同一條都要出現。
- **找到條號後，一律用 law_fetch.py 抓官方原文再引用。**快照不會隨修法更新；每一行是一項，全形空白縮排的是款。
- **更新：**`python -I scripts/law_snapshot.py`（全部），或在後面加法規代碼只更新一部。快照日期超過 6 個月，或基準表的修正日期變了，就重抓。腳本解析的條數和網頁不同時會拒絕寫入。
- **來源與驗證：**做法參考 taiwan-claude-legal 的 `laws/`（見 THIRD_PARTY_NOTICES.md）。2026-10-29 比對：
  - 兩邊共有的 5 部法規、2,295 條，內容一致。
  - 我們的版本保留項、款分行；和 law_fetch.py 抽查 26 條，逐行一致。
  - 原作的快照把同一條的各項黏成一段，看不出是第幾項。

## 4. 裁判

### 查詢與閱讀

- 系統：https://judgment.judicial.gov.tw/FJUD/default.aspx 。可依法院、案件類別、裁判字號、期間、案由、主文、全文關鍵字查詢。
- 網址中的 id 格式是「法院代碼,民國年度,字別,號次,西元裁判日期,序號」。
  - 例：`PCDV,114,聲,354,20260122,2` 是臺灣新北地方法院114年度聲字第354號，115年1月22日裁定。
  - 下列法院代碼已在 2026-10-28 打開裁判確認：TPSV 最高法院民事、TPSM 最高法院刑事、TPHV 高院民事、TPHM 高院刑事、KSHV 高雄高分院民事、PCDV 新北地院民事、PCDM 新北地院刑事、PCEV 新北板橋簡易庭、SJEV 新北三重簡易庭、TPDV 臺北地院民事、SLDV 士林地院民事、TYDV 桃園地院民事、CLEV 桃園中壢簡易庭、ULDV 雲林地院民事、TCDV 臺中地院民事；同日另確認 TYDM 桃園地院刑事、TCHV 臺中高分院民事、CYDV 嘉義地院民事、HLDV 花蓮地院民事、PTDV 屏東地院民事、SLEV 士林簡易庭、TCEV 臺中簡易庭、KSEV 高雄簡易庭、PTEV 屏東簡易庭。
  - 簡易庭裁判的官方 title 只寫簡易庭名稱，例如「士林簡易庭 114 年度士簡聲字第 29 號民事裁定」。引用時寫全名，例如「臺灣士林地方法院士林簡易庭114年度士簡聲字第29號民事裁定」。
  - 其他代碼以系統查詢結果為準，不要用猜的。
  - 舊裁判的 id 可能沒有最後的序號，例如 `TPSV,104,台上,1468,20150805`。
- **讀裁判的順序：**
  1. 先看主文，知道結果。
  2. 再看理由中「本院之判斷」或「經查」以下的段落，這才是法院見解。
  3. 「原告主張」「被告則以」「聲請意旨略以」是當事人的說法，不能寫成「法院認為」。
- 地院裁判可能被上級審改掉。重要的見解要查有無上訴、上級審結果，優先引用最高法院或已確定的裁判。

### 找類似案例

1. 已連接 TLR 時，先依 references/07 第 7 節找候選、追被引用的最高法院字號。沒接就從條文與關鍵字切入，例如「停止執行 & 非訟事件法第13條」。
2. 在官方系統限定近 3 到 5 年、同類程序；需要同一法院的見解時也限定法院。
3. 至少打開 3 則全文，記錄有利與不利的見解。
4. 註明個案事實和本案哪裡不同。

類似案例只能說明「法院可能怎麼看、怎麼算」，不能當成本案的結果或勝率。

### 用內建瀏覽器讀全文與核對

Python 直接下載 judgment.judicial.gov.tw 會被 bot-defense 擋下（2026-10-28 實測），要改用內建瀏覽器：

1. 開啟 https://judgment.judicial.gov.tw/FJUD/default.aspx 。
2. 讀 `scripts/fjud_verify.js`，把 `tests` 換成「id: [要核對的原文片段]」，在同一分頁用 javascript_exec 執行。
   - 一次可核對多則。
   - 要看某段前後文時，填 `SHOW`。
   - 片段可直接貼 TLR 的摘錄，換行與 TLR 插入的標記會自動去掉。
3. 先看 `title`（例如「臺灣新北地方法院 114 年度聲字第 354 號民事裁定」），確認法院、字號、民事或刑事都對。title 是「系統訊息」或空白，代表 id 錯誤或查無此案，不能引用。
4. 每一段都 ✓ 才算核實。出現 ✗ 時，看附上的官方原文差在哪裡；不能因為「意思相近」就照引。

id 裡的日期要精確。不知道日期時，回系統用字號查詢，或用 TLR 的 `search_judgments` 取 doc_id（格式相同）。

### 引用格式

格式：法院全名＋年度＋字別＋號次＋裁判種類（裁判日期），再附網址、查詢日，以及引用段落的原文或摘要。

例：臺灣新北地方法院板橋簡易庭114年度板聲字第235號民事裁定（114年10月28日）https://judgment.judicial.gov.tw/FJUD/data.aspx?ty=JD&id=PCEV%2C114%2C%E6%9D%BF%E8%81%B2%2C235%2C20251028%2C1 （查詢日 2026-10-28）

## 5. 判例、決議與大法庭（2026-10-28 核對法院組織法）

**判例**（法院組織法第57-1條）：
- 107年12月7日修正施行前選編的判例，如果沒有裁判全文可供查考，應停止適用。
- 未停止適用的判例，效力與未經選編為判例的最高法院裁判相同。
- 所以引用舊判例時，寫成最高法院裁判，並確認查得到全文。

**大法庭：**
- 最高法院設民事、刑事大法庭，裁判法律爭議（第51-1條）。
- 各庭的法律見解和先前裁判歧異時，要先徵詢其他各庭，再提案大法庭（第51-2條）。
- 大法庭裁定對提案庭提交的案件有拘束力（第51-10條）。
- 大法庭裁定可在法學資料檢索系統首頁的「大法庭專區」查詢。

## 6. 函釋

- 司法院的函釋：法學資料檢索系統的「判解函釋」。
- 法務部的函釋：法務部主管法規查詢系統。
- 地方政府法規網站（例如 laws.gov.taipei）也收錄部分中央函釋，可以當線索；引用時寫明發文機關、日期、字號，並以發文機關的原文為準。

## 7. 費用、地址、電話

- **費用：**
  - 看司法院「徵收費用標準」頁，並用條文自己算一次；兩者一致才採用。
  - 停止執行這類條文沒有明列的聲請，要查近期裁定怎麼收（見 references/03 第 4 節）。
  - 寫給使用者時一律加註「以法院通知為準」。
- **法院與地檢署的地址、電話：**從司法院「各法院資訊」或該機關官網取得。不要使用公文、簡訊或來電者提供的號碼。
